# Пульт сети

Пульт для Windows: VPN (AmneziaWG, свой сервер или ссылка vless/vmess/trojan и др.), zapret и прокси Телеграма в одном окне.

Здесь только готовые выпуски, исходного кода нет.

**Установка:** скачать `NetPanel-Setup.exe` из раздела [Releases](../../releases/latest) и запустить.
Установленный пульт сам проверяет этот репозиторий раз в сутки и обновляется с сохранением настроек.
Каждый установщик сверяется по `NetPanel-Setup.exe.sha256`.
